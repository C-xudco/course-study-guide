# 不会写代码也能安装：先选应用，再复制文件夹

[返回首页](../README.md)

## 0. 先分清三个东西

- **应用**：你打开来和AI聊天的软件，例如Codex、豆包、DeepSeek Harness。先保证它本身已能正常使用。
- **Skill**：告诉AI按什么流程做学案的一组文字文件；本项目不附带模型账号，也不是一个可双击启动的exe。
- **课程资料**：你自己的教材、讲义、题目。装好Skill后仍需上传或授权读取，不要放进公开GitHub仓库。

## 1. 点击与你的软件对应的教程

| 你已经能打开什么 | 点这里 |
|---|---|
| Codex | [Codex一步一步安装](INSTALL-CODEX.md) |
| 带本地Skill功能的豆包 | [豆包一步一步安装](INSTALL-DOUBAO.md) |
| DeepSeek Harness | [DeepSeek Harness一步一步安装](INSTALL-DEEPSEEK.md) |

普通DeepSeek网页版没有Harness的本地目录机制。普通豆包聊天也不能仅靠把文件放到硬盘就加载Skill；相应教程提供手动提供指令的备用方式。

## 2. 所有版本通用的下载动作

1. 在专用教程里点击“下载ZIP”。浏览器会保存压缩包，一般在“下载”文件夹。
2. 找到ZIP，右键解压/提取全部，打开解压出来的文件夹。
3. 按教程找到目标Skill文件夹；打开它应立即看到 `SKILL.md` 和 `references` 等内容。
4. 返回上一层，复制**整个Skill文件夹**。不要只复制里面的 `SKILL.md`，也不要把 `references` 分开放。
5. 粘贴到专用教程指定的运行目录。目录和调用方式三平台不同，不能混用。
6. 打开新会话，用一小段原创教材/一道母题做首次测试；先试1个单元，确认识别后再做整门课。

GitHub下载入口也可从分支页面的 **Code → Download ZIP** 进入；[GitHub官方说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)。只下载文字包不代表模型使用免费；实际应用的订阅/调用费用和额度以你自己的账户为准。

## 3. 怎样算真的装好了

至少确认两件事：应用实际识别到了目标Skill名称；用一份真实提供的短材料生成了符合要求的内容。不要仅让AI回答“已安装”就当成功，要求它先核对当前Skill目录/目录列表，并运行一个最小学习任务。

最小题量测试：上传2道原创母题，要求“仅出变式，每母题2个，不出基础题/模拟卷”。应保留2道母题＋4个变式，每题有完整详解和评价。改成0变式后应保留2道母题。教师模式两版题号应一致，学生无答案版不泄漏答案。

## 4. 更新、备份和卸载

更新前，将当前运行的**整个同名Skill文件夹**备份到Skill扫描目录以外。下载新版，按同一目录重新放入完整文件夹；不要仅覆盖入口而漏掉参考文件。不要把旧版留在另一个被扫描位置造成同名冲突。

资料、已生成学案和续作记录放在独立课程目录中，更新Skill不需要删除它们。停止使用时，移出已安装的Skill文件夹即可；若应用有禁用功能，也可按其官方说明关闭。不要删除整个应用数据目录。

## 5. 常见问题

| 现象 | 先检查 |
|---|---|
| 下载后打开只是文字 | 正常，Skill是指令；去应用里调用，不是双击运行。 |
| AI说找不到Skill | 是否选错分支、放错目录、多套一层文件夹或当前profile不扫描该目录？ |
| 看不到 `.md` 后缀 | 在资源管理器显示文件扩展名，确认不是 `SKILL.md.txt`。 |
| 只会讲概念，不出题 | 在请求中明确模式、题量、详解和本次实际资料。 |
| 数量不对 | 写清“每单元”还是“本次总量”，单道母题变式数另列。 |
| 没有PDF | 先确认宿主有文件导出工具；没有就复制正文到Word/WPS，检查公式后导出。 |
| 新对话忘了资料 | 重新提供材料/续作记录；Skill不等于跨会话记忆。 |
