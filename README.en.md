Source-grounded, progressive study guides and K–12 lesson preparation: intuition → prerequisites → concepts and conditions → worked examples → mother problems and purposeful variants → solutions and self-checks.

Download the matching branch ZIP, extract it, and copy the entire listed Skill folder into that host's discovered Skill directory. Do not install the whole repository or only `SKILL.md`. DeepSeek web chat is not DeepSeek Harness; the guide includes a manual-chat fallback.

All versions offer configurable counts, uploaded mother problems, graded variants, complete solutions, bilingual output when requested, explainable estimated difficulty, source tracking and learner/teacher modes. Codex includes optional Python helpers; Doubao has its own native instruction pack; DeepSeek Harness adds a detailed 11-stage full-unit workflow, seven-field mother cards and method prerequisites. Host file access, authenticated browsing and PDF export still require real host tools.

`main` receives documentation updates only; its original Skill implementation, helpers, tests and examples are unchanged. Existing Doubao and online-research branches remain separate. The DeepSeek branch includes all three packages for reference. The [original main snapshot](https://github.com/C-xudco/course-study-guide/tree/afb702f2822ea9649b23fd6104aa226b42efe787) remains accessible.

No passwords, private coursework, student data or generated learning packs are published. File/package checks do not establish that every model-generated answer is correct or that every host version has been tested end to end.
