# 长方形周长 · 原创合成教学资料

适用情景：已学长方形与周长含义的学习者；示例选择小学四年级，但不宣称对齐特定教材或课标。完整学案可使用实物、沿边描画和方格图建立直觉。

长方形的对边分别相等。周长是沿边界走一周的总长度。若长为 a、宽为 b，周长 P=a+b+a+b=2(a+b)。a、b 使用同一长度单位，结果仍为长度单位。

母题：长方形花坛长8米、宽5米，沿边围一圈，需多少米围栏？没有出入口，忽略围栏厚度。答案：(8+5)×2=26米。

可引入的变化：已知周长与长求宽；设置出入口求实际围栏长度；辨析把周长与面积混淆的解法。每种变化须明确不同的目标和必要条件。
