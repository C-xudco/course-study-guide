# 可选择的答题骨架

根据学科选择，写清适用条件，给一个本课程填写示范。字段是推理提示，不是可替代学科内容的万能句。双语模式提供等价中英表达；低年级用适龄短句。

## 计算/求解

已知与目标 → 检查适用条件 → 列关系式（解释符号/单位）→ 逐步求解（关键理由）→ 结果 → 代回/边界检查。

## 证明/辨析

命题及前提 → 证明策略 → 逐步推理及依据 → 覆盖必要情况 → 结论及适用边界；反驳则提供满足前提而违反结论的反例。

## 阅读/案例论述

明确问题与判断 → 引用或概述材料中的证据 → 解释证据如何支持判断 → 比较其他合理解释 → 条件、限制和结论。不得编造文本细节。

## 实验/探究

问题与可检验假设 → 变量与控制条件 → 方法和记录 → 数据/现象 → 解释与不确定性 → 结论和改进。区分观察事实与推断。

## 程序/算法

输入输出及约束 → 方法/数据结构 → 步骤或代码 → 正确性理由 → 复杂度（适用时）→ 正常、边界、异常输入检查。
