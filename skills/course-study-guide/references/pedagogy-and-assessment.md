# 教学递进、双语与模拟评估

## 不是按文件顺序堆摘要

先列可考查能力，再分知识单元。一个单元应围绕一个能独立练习的概念、方法或判断框架；合并仅有术语差别的碎片，拆开依赖不同方法的过大主题。维持“来源章节 ↔ 学习单元”映射，保证仍能回查课堂内容。

学习路径按依赖排序：生活/业务/科学情景 → 术语 → 精确定义 → 条件与边界 → 示范推理 → 通用方法 → 变式 → 综合。尚未讲到的知识可以前瞻提示，不能默默作为解题必需步骤。

每单元给能自查的目标，如“能区分 X 与 Y 并说明适用条件”；避免只写“了解/熟悉”。抽象内容先给最小实例，再推广。不要以增加篇幅替代必要的解释。

## 可调题组如何递进

难度标签服务教学，不把题号多或计算长等同于难：

| 层级 | 训练目的 | 可选题型 |
|---|---|---|
| 1 | 看懂与辨认 | 术语匹配、条件判断、解释一项区别 |
| 2 | 用一次规则 | 直接计算、简单应用、补完一个推理步骤 |
| 3 | 掌握母题 | 典型完整求解、证明、案例分析或程序设计 |
| 4 | 判断变化 | 改条件、反推、找错、比较方法、边界情形 |
| 5 | 迁移与综合 | 新情景、连接多个已学单元、论证选择与限制 |

题量遵循 `options-and-modes.md` 的配置。题组依学习目标涵盖基础、母题、变式和必要的迁移，不要求每组含全部五级；不要为凑数重复题目，也不强迫小学生做第5级综合题。层级用于教学排序，自动难度估计另用 `mother-variants-and-assessment.md` 的量表，两者不混同。

母题必须说明“识别信号 → 适用条件 → 决策 → 解题骨架 → 核验方法”。至少一个变式改变条件或所求目标，使学生必须重新判断；只换数值算同构练习，不能充作全部变式。

按学科调整：证明课检查前提和反例；编程课检查输入约束、正确性与边界；商科案例写证据、标准、取舍和可接受替代答案；论述课写观点、论据、结构与限制。没有唯一答案时给评分维度与合格示例，不制造唯一标准答案。

## 双语标准

仅在选择双语模式时应用以下标准；单语输出保留必要术语原文即可。

- 首次出现：中文名（English term, abbreviation），后续用法保持一致。一个英文词有多义时写本课程语境。
- 所有题干及子问题分别完整呈现中文与英文。数字、条件、否定词、单位和符号逐项相同。
- 答案包含对应英文的思路、关键理由、解题步骤和结论。共享一行公式可以，但不能只给公式加一句英文结果冒充双语详解。
- 英文是可用于考试的自然表达；中文帮助理解。保持含义一致，不要求逐词直译。
- 术语表包含中文、英文、缩写、简明双语定义、易混点和单元位置。符号另写含义及条件，不把公式变量混作普通术语。
- 开放题明确可接受的不同论证，英文示例同样保留假设与限制。

## 答案顺序与核验

知识讲解可有示范；自测题的答案集中置于该题组之后，保持编号一一对应。HTML 用折叠答案，直接跳到答案时应展开对应容器；PDF 不依赖交互隐藏，完整保留答案文本。

每题提供：方法理由 → 过程 → 结论 → 核验/边界。母题与难题补评分点和常见扣分原因。数值题独立重算（工具或第二种方法），不能只检查语言是否通顺；证明题逐步检查前提；代码题选择有意义的正常与边界输入；案例题核查证据与论点之间的支持关系。

## 可选原创模拟卷

先建立试卷蓝图：学习目标、章节权重、能力层次、题型、题数、分值、时长、来源依据。历史卷用于分析模式，不保证本期分布；时长分值无课程依据时标为作者练习设定。

按配置数量生成；两套时 A 卷侧重基础掌握和典型方法，B 卷提高辨析、迁移及综合要求。每卷覆盖本次核心目标且可独立完成，不引入未讲的新知识。不只换参数复制试卷。先根据教学目标设计，再独立求解核验可解性、数据合理性和负担。教师日常备课或只出变式时默认不生成模拟卷。

每卷结构：说明与练习设定 → 完整中英题目（含分值） → 答案分隔 → 中英详解 → 评分点 → 失分知识点回看链接。子题分值合计等于大题，大题合计等于卷面总分。可接受替代解法时写清。

范围外补充不计入核心卷面总分；若额外提供挑战题，单独列出分值及非必考性质。无历史卷时依据讲义目标原创，明确缺乏历史题型依据。

掌握核对表不能只是“看完”：分清能解释、能独立做母题、能应对变化；每条附可测试的题号和回看位置。
