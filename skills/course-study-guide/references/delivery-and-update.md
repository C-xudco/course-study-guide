# 检索、文件交付与更新质量

## 学案结构

1. 封面、课程与范围、资料版本、阅读说明。
2. 前置关键词/题型检索、目录、学习路径与先修提示。
3. 按依赖顺序排列的知识单元、按配置数量的分层题及对应详解。
4. 可选原创模拟卷：各卷完整题目后集中列答案与评分点。
5. 知识掌握核对表、公式/条件速查（适合该课程时）、双语学术术语表、来源与勘误。

以上结构按模块开关和语言调整，不强制输出全部内容。教师模式另有教案、课堂时间表、分层任务与出口检测；课堂分钟数相加应等于总课时。学生版默认只含任务/题目和留白，教师版包含答案、评价、追问和补救提示，分别核对防止答案泄漏到学生版。若用户明确需要带答案学生版，按其要求生成。

## 关键词检索

每条路由给出：常见中英题干词/缩写 → 题型或任务 → 区分相似题的条件 → 首先做什么 → 相关单元/母题/答案 → 对应模拟题。关键词从本课程的问法提炼，不携带其他课程的默认词库。

稳定 ID 用于数据与链接；最终页码用于 PDF 阅读，不把排版前预计页数写进成品。先完成内容和布局，再生成实际页码映射，回填导航并重新排版直至一致。PDF 应有目录、书签和内部链接，并可复制/搜索中文、英文和题号。

HTML 搜索覆盖中英文术语、同义词/缩写、单元 ID、练习及模拟卷的题干和答案。兼容大小写和常见空格差异；不能只搜标题。搜到折叠答案时自动展开；清空搜索恢复展示，不破坏导航。至少实测中文词、英文缩写、题号和答案内独有短语各一次。

## 可携带文件

PDF：正文为可选择文本；若图像内有重要公式/标签，在旁边给可搜索的说明。使用支持目标语言的字体；检查中文缺字、数学符号、上下标、公式断行和代码缩进。字体应选择当前设备可用且适合分发的方案，不硬编码某台电脑的路径。

HTML：把脚本、样式和必要资源内嵌，避免外部 CDN、联网字体、必须访问原资料路径的图片和数学渲染依赖。需要图片时嵌入数据或用可携带资源包并明确说明；默认优先单文件。无需登录或服务端。若提供学习进度，用可失败降级的本地存储，说明其仅属于当前浏览器，文件转发不包含学习记录。

可以完整转发实际 HTML/PDF 文件，不能把原作者本机 file 地址当成分享链接。未经用户要求，不上线网站或上传课程资料。教师要求 PDF 时保证 PDF 内有完整题目、答案、术语和检索，不依赖 HTML 才能学习。

## 必要核验

- 覆盖：来源台账与单元对应；缺讲义、不可读页和范围歧义显式列出。
- 教学：单元先修可达，术语先定义，题目存在实质递进；不靠空泛文本凑题数。
- 内容：中英条件/数值一致；答案独立核验；同题不同位置答案一致。
- 结构：稳定编号不重复，题目/答案对应，检索目标存在，模拟卷计分准确。
- 视觉：渲染并检查封面/导航、密集公式、长解答、题目与答案边界、表格、双语分页及文末。标题要跟随正文，避免英文题干/答案与对应中文被无提示拆开。
- 功能：PDF 内部跳转和页码、文字搜索；HTML 搜索、折叠答案直达、离线打开。先查相关格式技能及现有工具，用实际可用的方法验证。

结构可采用 `content-model.md`，运行 `python scripts/validate_workbook.py workbook.json`。结构通过不代表内容正确；视觉与解题核验另做。只宣称实际完成的检查。

## 持久化与更新

在用户课程目录下保存可编辑内容数据、来源清单与生成入口（采用脚本渲染时）。输出目录名按课程而定，不固定 midterm；不需要将所有中间调试文件交给用户。

重建前保留一版旧成品，避免无穷叠加备份。稳定 ID 支持导航和学习进度，新内容插入后重新生成目录/页码。更新章节相关的所有题目和参考答案，再核对术语和模拟卷是否仍成立。不要宣称旧内容逐字保留，除非真正做过比较。

交付时只简述本次覆盖、新增/修正、实际文件链接、仍缺少的关键材料。课时/卷面规则属练习假设时明确标记，不包装成老师要求。
