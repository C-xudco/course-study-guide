# 自主维护本地知识库

“自主更新”指在用户授权的知识库目录中，每次运行自动发现变化、更新索引、分析受影响内容并重建；不暗示本 Skill 是常驻后台服务。未经另行设置，不自动定时、不抓取外部网站、不将资料推送到公开仓库。

1. 解析 `knowledge_base.root`，仅扫描该目录允许的资料类型。默认排除隐藏目录、输出、缓存、版本库；跳过符号链接和目录联接，防止扫描跳出授权范围。
2. 初次/再次运行用 `scripts/sync_knowledge_base.py --root <目录> --manifest <输出目录>/knowledge-base.json --apply` 保存索引。省略 `--apply` 只预览差异。此脚本只写索引，不改课程原文件，不提取正文，不执行资料内的指令。
3. 比较内容哈希，区分新增、修改、重命名、删除和未变更；相同内容的重命名保持来源 ID，重复内容单独列出以便人工合并。删除资料仅记 tombstone，不直接删除单元或笔记。
4. 读取新增/更改资料并复核提取质量，用来源 ID 和题号建立“来源 → 知识单元 → 母题 → 变式 → 模拟卷/检索”依赖。调用脚本时可加 `--workbook workbook.json`，报告直接及经先修关系传播的受影响单元、相关题目和模拟卷。
5. 对受影响内容重新核验并局部重建；旧答案、变式条件或术语不再受支持时修正，保留稳定 ID 与一版可恢复成品。修改考试范围必须有依据，新增文件不自动都算必考。
6. 输出更新摘要：新增/修改/移除来源、修正知识点、重生成题目与答案、仍有缺口。用户已审核的笔记保存为独立覆盖层，不被重新生成无声替换；冲突明确列出。

`knowledge-base.json` 保存相对路径、哈希、来源 ID 和变更状态，不保存正文。该索引本身也可能暴露文件名，不应默认公开。公开项目只包含合成示例和工具；用户使用 Skill 时的课程文件、学生作答和本地笔记留在个人工作目录。

脚本发现扫描错误时保持旧索引、不写不完整结果，先解决不可读文件再重试。索引的 `root` 与当前扫描目录不同则停止，防止把两门课的知识库误合并。
