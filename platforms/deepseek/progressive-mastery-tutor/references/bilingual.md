# 双语输出：结构、术语与一致性

本文件在用户要求英文或双语时读取。目标不是“把最后一句结论翻译一下”，而是让两种语言都能独立用于学习、答题和核对。

## 1. 何时双语

- 用户明确说“双语/中英对照/中英文都要”：全文双语。
- 用户说“英文”：输出英文；题干、答案、说明都用英文，专有名词可保留中文原名。
- 用户说“中文”：输出中文；不要强行加英文。
- 用户语言混杂：按主要指令语言；必要时问一句“题干和答案都要双语吗？”不要默认全双语。

## 2. 结构

推荐**逐题配对**：

```text
### U01-M01-V02（中文）
题干：……
（必要时给中文小提示）

### U01-M01-V02（English）
Stem: ...
(Optional English hint)

#### 答案 / Answer: A-U01-M01-V02
**方法选择 / Method choice.** ...
**步骤 / Steps.**
1. ...
**结论 / Conclusion.** ...
**核验 / Check.** ...
```

也可以按题号分“中文部分/English Part”，但两部分的题号、顺序、数据必须一一对应。术语表用双语表格；教师教案的目标/活动/板书标签镜像，课堂用语可按用户要求以目标语言为主并给支持。

## 3. 必译范围

以下全部要中英对应，不能只译结论：

- 专业术语（首次出现给英文定义/中文原名）。
- 全部题干与子题；选项 A/B/C/D 的内容；单位。
- 数据表、图表标题、坐标轴、图例、标注。
- 关键推导步骤、公式条件、边界说明。
- 完整答案、评分点、可接受回答。
- 教师教案的目标、活动、追问、板书关键词、分层任务、出口检测、补救建议。
- 术语表、掌握核对表、续作记录（至少标题与字段）。

不需要逐字翻译的：文件名、来源编号、稳定题号、公式本身、代码标识符；这些保持原样。

## 4. 一致性检查清单

逐项对照，发现不一致先修正再交付：

- [ ] 数值、比例、区间、日期一致。
- [ ] 条件、否定、充分/必要关系一致（不要把“不一定”译成“一定不”）。
- [ ] 符号、变量名、下标一致（不要中文用 x、英文用 n）。
- [ ] 单位、量纲、精度/有效数字一致。
- [ ] 选项顺序与内容一致；答案字母一致。
- [ ] 解的个数、范围、边界一致。
- [ ] 图表标签、图例、坐标轴一致。
- [ ] 答案结论、评分点、分值一致。
- [ ] 题号、答案编号、单元/母题编号一致。
- [ ] 英文是自然的目标年级表达，不是逐字直译。

## 5. 英文写作要求

- 用目标年级能读懂的句子；长句拆分。
- 首次出现术语给简短英文定义；不要假设读者懂中文术语。
- 数学/科学表达用标准英文：`Let x be ...`、`Solve for ...`、`Show that ...`、`Hence ...`。
- 避免歧义代词（it/this/they）；指代具体对象。
- 指令动词清楚：`Find`, `Explain`, `Prove`, `Describe`, `Compare`, `Design`。
- 答案中的推导与中文版步骤一一对应，不额外跳步。
- 文化/情境例子换成本地可理解的版本时，保持数学/科学结构不变，并说明改编。

## 6. 术语表

```text
| 中文 | English | 符号/单位 | 定义（双语） | 常见误解 | 出现位置 |
| 一元一次方程 | linear equation in one variable | ax+b=0, a≠0 | ... | 把分式方程直接当一元一次方程 | U01 第4步 |
```

- 只收实际出现的术语；不要堆词典。
- 英文术语用学科通用说法；有多种说法时选目标课程常用的一种，必要时给别名。
- 定义与资料一致；作者补充标 `[作者补充]`。

## 7. 常见问题

| 问题 | 后果 | 修正 |
|---|---|---|
| 只译最后结论 | 英文读者无法跟推导 | 题干、子题、关键步骤、答案全镜像 |
| 中文用 x，英文用 n | 对照困难/答案错位 | 统一符号；必要时在术语表说明 |
| 否定译反 | 答案条件相反 | 专门核对否定词：not, only, at least, at most, cannot |
| 单位漏译/换算 | 数值正确但答案错 | 单位逐项对照；换算写清 |
| 选项顺序变了 | 答案字母不一致 | 保持选项顺序与字母 |
| 英文过度直译 | 不可用于答题 | 按目标年级重写，保持逻辑与数据 |
| 双语评价标准不同 | 评分不公 | 评分点、分值、可接受回答镜像 |

## 8. 歧义处理

翻译后如果出现以下情况，加“译者注 / Translator's note”，不要静默选一种：

- 中文一词多义导致条件不同；
- 英文单复数/冠词导致对象不同；
- 单位/符号在两种语言中习惯不同；
- 文化情境改动改变了数学模型；
- 原文本身有歧义，两种读法都合理。

译者注要说明：歧义在哪、采用哪种读法、另一种读法会怎样影响答案。若影响核心结论，先问用户。

## 9. 双语自检

- [ ] 题干、子题、选项、数据表全部双语。
- [ ] 关键推导与完整答案双语，不是只译结论。
- [ ] 数值/条件/否定/符号/单位/选项顺序一致。
- [ ] 英文自然、可用于答题；术语首次有定义。
- [ ] 术语表、评分点、核对表双语。
- [ ] 有歧义时加译者注，未静默选择。
- [ ] 题号/答案编号/单元编号两种语言一致。
