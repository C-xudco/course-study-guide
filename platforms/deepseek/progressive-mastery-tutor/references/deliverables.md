# 成品组装：学案、练习、教案、模拟卷、检索与续作

本文件在组装成品、写教师教案、出模拟卷、做检索表、分批续写或更新资料时读取。先确定模式与模块，再按规格组装；不要把所有模块无差别堆给用户。

## 1. 模块目录

| 编号 | 模块 | 内容 | 默认 |
|---|---|---|---|
| M0 | 资料核对 | 资料清单、读取状态、缺口、答案核验、来源标签 | 必选，不可省 |
| M1 | 学案 | 目标、先修、情景、术语、原理、示范、方法、易错、题组、详解、掌握检查 | 自学默认 |
| M2 | 练习册 | 题组 + 对应答案；可按单元/整册 | 自学默认 |
| M3 | 母题变式库 | 母题卡 + 变式卡 + 详解 + 评价 | 自学/仅变式默认 |
| M4 | 双语详解 | 与 M1/M2/M3 组合的双语答案与推导 | 双语时默认 |
| M5 | 答题模板 | 计算/证明/程序/阅读/实验/案例/论述的空白骨架 | 可选 |
| M6 | 教师教案 | 目标、时间表、活动、追问、板书、分层、出口、补救 | 教师备课默认 |
| M7 | 评价表 | 逐题评价 + 汇总；标教学预估 | 默认 |
| M8 | 关键词检索 | 学案开头的检索表 | 默认 |
| M9 | 模拟卷 | 原创练习卷 + 答案 + 评分点（用户明确要求才改编） | 考试复习默认 2 |
| M10 | 掌握核对表 | 目标×证据×自评×补救 | 默认 |
| M11 | 术语表 | 术语、定义、英文、符号/单位、误解、位置 | 默认 |

教师备课默认两套：

- **学生版**：M1/M2/M10，无答案、无评价、无教师备注；可含目标和任务。
- **教师版**：M1/M2/M3/M6/M7/M8/M10/M11，含答案、评价、教案。

用户只要教师版时，关闭学生版；用户只要学生版时，明确“无答案，不能用于自测核对”。

## 3. M1 学案

顺序：

1. 成品头：课题、年级/基础、语言、模式、参数快照、资料编号。
2. **关键词检索表**（见 §7）——放在学案开头。
3. 资料清单与来源标签图例。
4. 单元正文，严格 11 步。
5. 题组后的集中详解。
6. 掌握核对表/术语表（如启用）。
7. 续作记录。

要求：

- 答案不穿插在题干后；集中在题组后。
- 检索表放在开头，不放到文末。
- 单元多时，每个单元都可独立阅读；不依赖上一单元的答案。
- 不在学案里堆教师教案内容；教师版另加。

## 4. M2 练习册

- 题组 + 对应答案；可按单元或整册。
- 每题有编号、题量说明、评价（可在答案后或单独 M7）。
- 不写长篇教学叙事；需要讲解时链接回 M1 的单元/步骤。
- 学生版无答案；教师版含答案。
- 题量按参数；不因“练习册”名义硬凑题。

## 5. M3 母题变式库

- 母题卡 7 字段；变式卡 4 说明字段；逐题详解；评价。
- 来源、编号、题量分配表齐全。
- 不依赖学案也能独立使用；必要时给一句“前置方法”提示。
- 上传母题超额时，列“纳入/未纳入”表与理由。

## 6. M4 双语详解

- 与 M1/M2/M3 组合；不是单独一套题。
- 逐题配对：中文题干/答案后紧跟英文；或按题号成对分节。
- 术语表双语；关键推导、评分点、边界说明都镜像。
- 完整规则见 `bilingual.md`。

## 7. M8 关键词检索表

放在学案开头。列固定为：

```text
| 题干关键词/缩写 | 题型 | 区分判据 | 第一解题步骤 | 单元/母题/答案编号 |
| 一元一次方程 | 计算 | 只含一个未知数且次数为1；分母不含未知数 | 去分母/去括号，把未知项移到一边 | U01 / U01-M01 / A-U01-M01 |
```

要求：

- 覆盖所有母题与变式；基础题按需收录。
- **区分判据**要能区分最近似的题：写“看到什么/缺什么/问什么”就选这类，而不是重复关键词。
- **第一解题步骤**是具体动作（读表取参数、设未知数、画受力图、定位文本证据），不是“用公式”。
- 编号链接到单元、母题、答案；同一题在不同语言下编号不变。
- 表后加一句警告：关键词只用于定位，不能只凭关键词套公式；先核对区分判据与适用条件。
- 不编造页码；没有真实排版结果不写 PDF 页码。

## 8. M9 模拟卷

### 8.1 基本原则

- 默认原创，不复制资料原题；只有用户明确要求改编时，才标注“改编自 Sxx 第x题”并做实质改动。
- 依据资料的能力目标与题型设计；**不声称预测考试**。
- 默认 2 套（仅考试复习场景）；教师备课/仅变式默认 0；用户可关闭。
- 两卷各自独立可完成；不共享必须依赖的数据。
- 完整题目、集中答案、评分点；答案在该卷题目之后，不穿插。
- 分值求和正确；无官方依据时，时长/分值标“练习设定”。

### 8.2 蓝图

```text
| 题号 | 题型 | 分值 | 知识点 | 认知过程 | 难度 | 原创说明（默认原创） |
| P1-Q01 | 计算 | 5 | ... | 应用 | 2 | 原创 |
| ... |
| 合计 | | 100 | | | | |
```

- 合计=各题分值之和；逐项核对，不写“约 100 分”。
- 覆盖单元权重与能力目标；不要只考记忆题。
- 难度分布合理：基础/中档/提高都有；不人为堆超纲题。
- 时长为建议值；没有官方依据时写“建议 90 分钟（练习设定，非官方）”。

### 8.3 答案与评分点

- 每卷答案集中在该卷题目之后；逐题给四段式（可精简，但不省略关键步骤）。
- 评分点写到可操作：如“列式 2 分，求解 2 分，结论/单位 1 分”，合计=该题分值。
- 开放题给评分维度与可接受回答，不假装唯一答案。
- 程序题：未实际运行就写“未运行”；运行了才写命令/结果。
- 最后写“分值校验：Σ=100”。

## 9. M6 教师教案

### 9.1 头部

- 课题、年级/基础、课时长度、语言、资料依据。
- 教学目标（可检验，3–5 条）、重点、难点。
- 课标对齐：只有用户提供标准文本时标注具体条目；否则写“未提供课标文本，未做条目标注”，不虚构。

### 9.2 时间表

```text
| 时间 | 环节 | 教师活动 | 学生活动 | 追问 | 板书/媒体 | 对应目标 |
| 0–5 | 先修诊断 | ... | ... | ... | ... | 目标1 |
| ... |
| 合计 | 45 分钟 | | | | | |
```

- 分钟数合计必须等于课时；未指定时按 45 分钟并标“假设”。
- 每段有明确活动与追问，不写“讲解知识点”这种空话。
- 追问要能暴露误解，不只问“懂了吗”。
- 板书/媒体写关键结构，不写“放 PPT”。

### 9.3 板书

- 用文字布局说明：左侧目标/核心关系，中间示范/骨架，右侧易错/出口题。
- 关键公式、符号、单位、条件必须上板书。
- 不伪造图片；需要图时用文字描述或简单 ASCII/表格。

### 9.4 分层任务

- 基础/提高/拓展三层；每层给任务与答案。
- 拓展层若超范围，标 `[范围外拓展]`，不计入核心掌握。
- 不按学生贴标签；用“任务层”而非“学生层”。

### 9.5 出口检测与补救

- 出口检测 2–3 题，3–5 分钟，覆盖目标；给判据。
- 补救：错因 → 5 分钟重教 → 同类练习 → 复查。
- 不写“学生普遍掌握良好”之类无证据结论；写“若能做到……则视为达标”。

### 9.6 学生版/教师版

- 学生版：目标、任务、题组、空白答题区；无答案、无评价、无教师备注。
- 教师版：含答案、评价、教案、分层答案、出口判据、补救建议。
- 两版题目与编号一致；不要在学生版里留下答案痕迹。

## 10. M10 掌握核对表

```text
| 学习目标 | 证据（题号/任务） | 自评（未掌握/基本/熟练） | 补救 |
| ... | U01-B01、U01-M01 | | 回到第5步，重做... |
```

- 目标与题目对应；不写无法观察的目标。
- 自评是给学生用的，不伪造教师观察结果。
- 补救具体到步骤/题类。

## 11. M11 术语表

```text
| 术语 | 定义 | English（双语时） | 符号/单位 | 常见误解 | 出现位置 |
| ... | ... | ... | ... | ... | U01 第4步 |
```

- 只收本单元/本包实际出现的术语；不堆词典。
- 定义与资料一致；作者补充要标。
- 双语时英文自然、可用；不逐字直译。

## 12. 续作记录

每批末尾：

```text
## 续作记录
- 当前配置：mode=自学；scenario=常规；language=中文；base/单元=2；mothers/单元=1；variants/母题=3；totalMothers=未设；modules=M0,M1,M2,M3,M7,M8,M10,M11
- 资料编号：S01（已读全文）、S02（部分读取）
- 已完成：U01（B01–B02、M01、V01–V03）；U02（B01–B02）
- 缺口/待确认：U02 的图3-2缺失，第5题未生成
- 下一步：U02 的 M01 与 V01–V03
- 稳定编号变更：无
```

要求：配置、资料编号、已完成单元/题号、缺口、下一步五项必备；不要写“后续继续”这种无信息的话。

## 13. 分批与断点

- 默认一次一个单元；用户要多个单元时按顺序写，每个单元完整。
- 输出接近上限时，停在单元末或答案末；不要停在半道推导。
- 明确写“本批到 X 为止；下一批从 Y 开始；回复‘继续’即可”。
- 不通过删答案、压缩讲解来塞进一批；宁可分批。

## 14. 更新协议

用户补充资料时：

1. 差异表：新增/修改/删除/冲突。
2. 影响清单：知识点、母题、变式、答案、术语、检索。
3. 更新内容：保留稳定编号与用户已审核内容；修订标 `R1`；废弃标 `[已废弃]`。
4. 复核：受影响答案、题量、分值、双语镜像。
5. 更新续作记录与检索表。

只处理用户实际重新提供的资料；不声称后台扫描文件夹或跨对话永久记忆。

## 15. 交付格式

- 默认 Markdown：标题、表格、LaTeX 公式（`$...$`/`$$...$$`）、代码围栏。
- 提醒：复制到 Word/WPS 后检查公式是否正常转换，再导出 PDF。
- 若当前环境有 Office/PDF 导出能力且用户要求：生成真实文件、重新打开验证、用 `present` 呈现实际路径；否则不要声称有文件。
- 不提供假下载链接、假网盘地址、假页码；没有真实排版结果不写 PDF 页码。
- 文件命名用稳定编号，如 `U01-学案.md`、`U01-M01-变式库.md`；同一批文件命名一致。

## 16. 成品自检

- [ ] 学案检索表在开头，5 列齐全。
- [ ] 答案集中在题组后；学生版无答案。
- [ ] 模拟卷原创说明（默认原创；改编需用户明确要求）；两卷独立；分值求和正确；答案与评分点齐全。
- [ ] 教师时间合计=课时；学生版/教师版差异清楚。
- [ ] 术语表/核对表与目标对应。
- [ ] 续作记录五项齐全。
- [ ] 没有伪造文件、链接、页码、统计或课堂结果。
