# 题目评价：知识维度、认知过程与五维难度

本文件在给题目写评价、做难度校准或生成评价表时读取。所有评价以**目标学习者**为参照，不是以作者或模型为参照。没有学生实测数据时，一律标“教学预估”。

## 1. 每题必填字段

```text
- 知识点：……（具体到本单元的概念/关系，不写“综合”）
- 知识维度：程序/计算（主）；概念（次，可选）
- 认知过程：应用、分析（可多选）
- 难度：
  - 先修要求：2（只用到一个已学等式性质）
  - 推理步骤：3（列式→求解→检验，含一个决策点）
  - 抽象程度：2（具体数量关系，符号一层）
  - 迁移要求：2（与示范同结构，换情境）
  - 表征复杂度：2（文字+简单表格）
  - 均值：2.2 → 综合等级：2
- 置信度：中；主要不确定性：目标年级的运算熟练度未知
- 性质：教学预估（无学生实测）
```

字段必须齐全；不能只给一个“难度：中等”。证据要具体到题目特征，不能写“较难”“综合性强”这类空话。

## 2. 知识维度（单选主维，可加次维）

| 维度 | 判断问题 | 典型任务 |
|---|---|---|
| 概念 | 主要考定义、分类、性质辨析？ | 判断正误、举例/反例、解释概念 |
| 程序/计算 | 主要考按步骤运算/操作？ | 解方程、化简、代入、单位换算 |
| 推理论证 | 主要考证明、推导、因果链？ | 证明、说明理由、反驳 |
| 表征转换 | 主要考文字/图/表/符号/程序互译？ | 看图列式、读表、画图、转代码 |
| 情景应用 | 主要考建模、决策、解决真实情境？ | 应用题、实验设计、案例分析 |

一题只选一个主维；若确实跨维，在备注写次维，不要用“综合”代替判断。主维决定它在检索表里的归类。

## 3. 认知过程（可多选）

| 过程 | 行为动词 | 判断要点 |
|---|---|---|
| 记忆 | 回忆、识别、复述 | 主要靠再认/提取，不需推理 |
| 理解 | 解释、举例、分类、比较 | 能用自己的话说明关系 |
| 应用 | 执行、计算、使用 | 把已知方法用到熟悉/新情景 |
| 分析 | 拆解、归因、比较、诊断 | 找结构、找错因、区分条件 |
| 评价 | 判断、 critique、选择 | 按标准判断优劣/合理性 |
| 创造 | 设计、构造、规划、创作 | 产生新方案/新题/新结构 |

可多选，但不要把所有题都写成“理解、应用、分析”。长题、多计算不等于高阶：多步计算可能只是“应用”；短题也可能需要“分析/评价”。

## 4. 五维难度锚点（1–5）

### 4.1 先修要求

- 1：只需本单元刚复习的即时知识。
- 2：需一个简单旧知识（如一次运算、一个定义）。
- 3：需 1–2 个已学概念并能调用。
- 4：需多个先修，或先修掌握不牢会明显受阻。
- 5：需跨单元/未复习的先修，或需自行补桥。

### 4.2 推理步骤

- 1：一步直接得到。
- 2：两步，路径明确。
- 3：3–4 步，含一个决策点。
- 4：5–6 步，或含两个决策点/一次分类。
- 5：多步嵌套、多情况、需构造/反证/自行设计路径。

### 4.3 抽象程度

- 1：具体实物、具体数字、直观图。
- 2：一个符号/未知数，关系直接。
- 3：公式/关系一层抽象，需代入或变形。
- 4：多符号/参数，需区分变量与常量。
- 5：形式化、一般化、量化关系，或需自行建立模型。

### 4.4 迁移要求

- 1：与示范同结构、同表征，只换数字。
- 2：换情境/数字，方法明示。
- 3：换表征或增删一个条件，需判断方法仍适用。
- 4：新情境中需自己选方法/建模。
- 5：远迁移，需组合多个已学知识或构造新策略。

### 4.5 表征复杂度

- 1：纯文字，单一表征，信息齐全。
- 2：文字+简单表格/一个图，信息基本齐全。
- 3：文字+图/表，需提取关键信息。
- 4：多表征并存，有冗余或需筛选信息。
- 5：多表征互译、信息缺失/冲突，需自行补桥或判断。

## 5. 计算与等级

```text
mean = (先修 + 步骤 + 抽象 + 迁移 + 表征) / 5
level = floor(mean + 0.5)   # 四舍五入到 1–5 整数，不用银行家舍入
```

显示规则：

- 均值保留 1 位小数；
- 等级为 1–5 整数；
- 同时给五项分数和每项一句证据；
- 不把等级写成“2.5 级”；等级必须是整数。

示例：`(2+3+2+2+2)/5 = 2.2 → 2`；`(3+4+4+4+3)/5 = 3.6 → 4`。

## 6. 置信度

| 置信度 | 适用 |
|---|---|
| 高 | 来源完整、目标年级明确、题目无歧义、难度特征清晰 |
| 中 | 来源基本完整，但目标学习者信息有限或有一处歧义 |
| 低 | 来源缺失/题干不清/目标年级未知/评价依赖假设 |

必须写“主要不确定性”，例如：目标年级运算熟练度未知；题干缺图；未提供学生数据；双语翻译可能改变条件。置信度不是难度，不要混用。

## 7. 两个完整示例

### 示例 A：低阶程序题（教学预估）

题目：解方程 `2x + 3 = 11`。

```text
- 知识点：一元一次方程的解法（移项、系数化为1）
- 知识维度：程序/计算
- 认知过程：理解、应用
- 难度：
  - 先修要求：1（只需等式性质，本单元刚复习）
  - 推理步骤：2（移项→除以2）
  - 抽象程度：2（一个未知数，关系直接）
  - 迁移要求：1（与示范同结构，只换数字）
  - 表征复杂度：1（纯文字/符号，信息齐全）
  - 均值：1.4 → 综合等级：1
- 置信度：高；主要不确定性：无（题目完整）
- 性质：教学预估
```

注意：这不是“记忆题”，因为要执行两步程序；但也不是高阶题。计算量小、步骤少，等级低是合理的。

### 示例 B：高阶迁移题（教学预估）

题目：给出一张“不同套餐月费与流量”的表格，要求建立一个分段模型，判断某用户在某流量区间应选哪个套餐，并说明当流量继续增大时结论是否改变。

```text
- 知识点：分段函数/一次关系、实际约束、方案比较
- 知识维度：情景应用（主）；表征转换（次）
- 认知过程：分析、评价、创造
- 难度：
  - 先修要求：4（需一次函数、不等式、分段讨论）
  - 推理步骤：4（读表→建模→比较→边界讨论）
  - 抽象程度：4（多参数，需区分变量/常量）
  - 迁移要求：5（新情境，需自行建模并评价）
  - 表征复杂度：4（文字+表格+多方案信息）
  - 均值：4.2 → 综合等级：4
- 置信度：中；主要不确定性：目标年级是否已学分段讨论
- 性质：教学预估
```

注意：认知过程有“评价/创造”，难度也高，但两者是分开判断的；不是因为题目长才给高阶。

## 8. 批量评价表

题目多时可用汇总表，但每行仍要有五维证据或指向逐题块：

```text
| 题号 | 知识点 | 维度 | 认知过程 | 先修 | 步骤 | 抽象 | 迁移 | 表征 | 均值→等级 | 置信度/不确定性 |
| U01-M01-V02 | ... | 表征转换 | 应用、分析 | 2（...） | 3（...） | 3（...） | 3（...） | 3（...） | 2.8→3 | 中：... |
```

汇总表不能替代逐题证据；若表格太宽，改用逐题块 + 末尾汇总。

## 9. 禁止事项

- 不写“正确率约 X%”“区分度良好”“难度系数 0.7”等无学生数据的统计。
- 不写“标准化测评表明”“根据考试数据”等无来源结论。
- 不把“题目长/计算多”直接判为高阶。
- 不把认知过程与难度混为一个分数。
- 不省略五维证据；不只用“中等/较难”。
- 不把“教学预估”写成“实测难度”。

## 10. 评价自检

- [ ] 每题知识点具体；维度有主维；认知过程可多选但不过度。
- [ ] 五维都有 1–5 分和一句证据。
- [ ] 均值计算正确；四舍五入为整数等级。
- [ ] 置信度与主要不确定性已写。
- [ ] 标“教学预估”；无正确率/区分度等伪造数据。
- [ ] 认知过程与难度分开判断；长题没有被自动判为高阶。
