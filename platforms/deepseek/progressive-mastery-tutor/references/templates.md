# 可复制骨架

本文件提供直接复制、替换占位符的 Markdown 骨架。占位符用 `……` 表示；不要原样交付占位符。

## 1. 成品头

```text
# 《……》递进式学习包

- 模式：自学 / 教师备课 / 仅母题变式
- 场景：常规 / 考试复习
- 语言：中文 / 英文 / 双语
- 目标学习者：……年级 / ……基础
- 课时：……分钟（未指定时按 45 分钟假设）
- 题量：每单元……基础 + ……母题 + 每母题……变式；母题总数……
- 模块：M0、M1、……
- 资料编号：S01、S02……

> 来源标签：[课程明确] 用户资料明确写出；[必要先修] 更早内容；[作者补充] 为讲通而补；[范围外拓展] 超出范围。
```
