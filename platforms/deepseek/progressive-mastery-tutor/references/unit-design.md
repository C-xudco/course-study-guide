# 单元设计：依赖规划、11 步教学与学科适配

本文件在规划单元、写讲解、控制难度时读取。目标是让单元围绕“可迁移能力”组织，而不是把资料目录或术语表机械复制成课。

## 1. 先规划，后编写

### 1.1 依赖规划步骤

1. 从资料中列出目标能力（能用知识做什么），不要先列章节名。
2. 为每个能力找必要先修；先修不是“越全越好”，只保留本单元真正要用的。
3. 按“先修 → 依赖它的能力”排序；同一层内按资料顺序或由具体到抽象排序。
4. 合并过碎内容：一个单元只承载一个独立能力；两个独立能力拆开。
5. 给每个单元分配题量、掌握证据和资料依据。
6. 检查：有没有单元只是术语堆叠？有没有单元缺先修？有没有单元实际上在重复同一能力？

### 1.2 单元计划表

```text
| 单元ID | 可迁移能力 | 必要先修 | 资料依据 | 基础/母题/变式 | 掌握证据 |
| U01 | 能用一元一次方程解决一类实际数量关系 | 有理数运算、等式性质 | S01 P80–P88 [课程明确] | 2/1/3 | 能独立列式并检验 |
| U02 | ... | U01 | ... | 2/1/3 | ... |
```

表后写“实际题量说明”：有覆盖、超额或 0 母题时，说明原因和实际数量。

### 1.3 单元粒度

- 一个单元 = 一个可迁移能力 + 它必需的先修概念。
- 纯术语单元（如“几个名词”）并入相邻能力单元，在题组中顺带练；不要为每个术语出一套题。
- 两个能力如果必须分开练（例如“解方程”与“用方程建模”），拆成两个单元，不要硬塞成一个。
- 若一个单元没有可迁移的核心关系，允许 0 母题，用基础题 + 迁移任务；不要为凑数造母题。
- 单元数量多时，先给课程地图，再按用户选择分批；不要一次输出全部导致每单元被压缩。

## 2. 11 步固定顺序

完整M1学案每一步写“内容 + 质量判据”。学科不适用时换成规则/模型/案例/程序；仅变式/评价等任务按入口的模块裁剪执行，不强塞完整11步。

### 第 1 步：可检验的学习目标

写 3–5 条，使用可观察动词：解释、计算、证明、设计、诊断、评价、建模。每条包含：

- 条件：在什么情境/给定什么信息下；
- 行为：做什么；
- 标准：做到什么程度算达标。

避免“理解……”“掌握……”单独出现；如果必须用，补一句可观察证据。

### 第 2 步：先修回顾

- 1–3 个微任务，带答案，5 分钟内可完成。
- 只复习本单元真正要用的先修；不把旧单元重讲一遍。
- 先修缺口严重时，加“补缺微单元”，不要靠拉长本单元硬讲。
- 微任务不计入“2 基础题”的题量；在文中标“先修检查（不计入题组）”。

### 第 3 步：最小情景建立直觉

- 一个具体、熟悉、变量少的情景；数字小，图简单。
- 先让用户预测/估算，再形式化；让直觉先落地。
- 说明这个情景的边界：什么变了结论会变。
- 不要一上来给一般式或公式表。

### 第 4 步：术语和定义

- 只列本单元必需的术语；每个给：定义、符号/单位（如适用）、一个正例、一个反例或易混点。
- 术语首次出现时给读法；不要用未定义的术语解释另一个术语。
- 不写成词典；能用一个例子说清的，不堆三段定义。

### 第 5 步：原理/公式及符号、条件、边界

- 符号：每个符号的含义、单位、取值范围。
- 条件：公式/原理成立的前提；隐含假设。
- 边界：退化情形、极端值、失效条件。
- 推导：给思路或关键步骤；资料未给推导时标 `[作者补充]` 或说明“按资料直接给出”。
- 常见误用：至少一个“看起来对但不成立”的例子。
- 无公式学科改为“原理/规则/模型及条件”，结构不变。

### 第 6 步：完整示范

- 从读题到结论完整走一遍，不只列步骤。
- 标关键决策点：为什么选这个方法；还有什么方法；如果条件变了会怎样。
- 展示检查：单位、范围、解的个数、合理性。
- 示范中使用的方法必须已在本单元或先修中出现；否则先补方法。

### 第 7 步：通用方法

- 编号骨架：读题 → 识别关系 → 选择方法 → 执行 → 检验。
- 每步给检查点/决策点，不只给动作名。
- 与母题卡、变式对应：说明哪些步骤在变式中会变。
- 给一个“方法选择表”：看到什么信号选什么方法，避免只背套路。

### 第 8 步：易错辨析

- 错误 → 为什么错 → 怎么发现 → 怎么改。
- 至少一个反例或边界例；不要只说“注意不要粗心”。
- 把易错点与后面的题组对应，让用户在题中识别。

### 第 9 步：递进题组

- 顺序：基础题 → 母题 → 变式；难度递进。
- 每题有稳定编号；题量与参数一致。
- 基础题只改示范中的一个条件；第二题可组合两个步骤。
- 母题是单元核心关系的代表题；变式做迁移。
- 每题后不立即给答案；答案集中在第 10 步。

### 第 10 步：对应详解

- 按题号逐题给，四段式：方法选择理由 → 必要步骤 → 完整结论 → 核验/边界。
- 计算保留关键中间结果和单位；证明检查前提、分类、反例；程序区分推理与实际运行；开放题给可接受回答与评分维度。
- 不写“同上”“略”；不省略关键推导。

### 第 11 步：掌握检查

- 3–5 个出口任务/自评项，覆盖本单元目标。
- 给判据：做到什么算掌握；未达标怎么办（回到哪一步、做哪类题）。
- 不伪造课堂结果；不写“学生平均正确率”。
- 可给自评表：目标 | 证据 | 自评（未掌握/基本/熟练） | 补救。

## 3. 最短时间理解的写法

目标：让使用者在最短时间内建立可用直觉，而不是读一篇完整教科书。

- 先具体后抽象：例子 → 直觉 → 定义 → 公式。
- 一屏一个核心概念；不要把五个概念塞进一段。
- 每个核心概念给“三句话总结”+ 一个反例/边界。
- 示范先于练习；基础题只改一个条件，再逐步加难。
- 新符号首次出现时给读法、含义、单位；之后不再重复解释。
- 不把定义堆成词典；不引用尚未介绍的术语。
- 每讲完一个关键点，给一个即时小检查（1 题或 1 问），答案紧邻或放题组后。
- 用对比表区分易混概念；用“如果……会怎样”训练边界感。
- 长单元用“核心线”串起来：一句话说明本单元到底在解决什么问题。

## 4. 方法白名单

写详解前，先在单元内列：

```text
本单元已介绍方法：……
可用的先修方法：……
显式补充方法（标[作者补充]）：……
```

规则：

- 答案只能使用以上方法；不得突然使用未介绍的方法。
- 需要新方法时，在答案前插一个短“补充方法”框：是什么、为什么需要、条件、一个微型示范；标 `[作者补充]`。
- 资料中的解法若超出范围，先判断能否用已介绍方法替代；不能替代时，先介绍再使用，并说明。
- 白名单也约束题干：题干不能要求用户使用未学方法才能读懂。

## 5. 学科题型适配

| 学科 | 常用题型 | 答案重点 | 常见失误 |
|---|---|---|---|
| 数学 | 计算、证明、建模、图像、反例 | 关键中间结果、单位、范围、解的个数 | 跳步、忽略定义域、分类不全 |
| 物理 | 计算、实验、图像、误差、建模 | 公式条件、单位、有效数字、极限情形 | 单位不一致、忽略摩擦/阻力等条件 |
| 化学 | 计算、方程式、实验、推断 | 配平、守恒、条件、现象与结论对应 | 方程式未配平、现象与结论混淆 |
| 生物 | 概念解释、图表、实验、论述 | 变量、对照、证据链、术语准确 | 用目的代替结论、忽略对照 |
| 语文 | 阅读、鉴赏、写作、语言运用 | 文本证据、结构、表达效果、评分维度 | 空泛套话、脱离文本 |
| 英语 | 阅读、语法、写作、听说 | 语境、语法形式、篇章连贯、任务完成度 | 只译结论、忽略语域 |
| 历史 | 材料分析、比较、论述 | 时空定位、史料证据、因果、史观 | 以论代史、忽略史料局限 |
| 政治/道法 | 材料分析、辨析、论述 | 概念准确、材料结合、逻辑层次 | 堆术语、脱离材料 |
| 地理 | 图表、区域分析、成因、规划 | 空间尺度、要素关系、数据证据 | 只背结论、忽略尺度 |
| 信息技术 | 程序、调试、算法、项目 | 输入输出、边界、复杂度、测试 | 只写代码不说明推理、未测边界 |

不是每科都要出所有题型；按资料和目标选择，避免“为多样而多样”。

## 6. 中小学尺度（K-12）

- **方法**：只用资料已出现或明确先修的方法；不以超纲方法制造“迁移”。
- **数字**：在目标年级的运算范围内；不故意用大数/繁分数制造难度。
- **术语**：先定义再用；不引入未解释的符号。
- **阅读**：题干简短、信息分层；避免无关背景；图表清晰。
- **迁移**：换情境但方法仍在范围内；远迁移要标 `[范围外拓展]`，与核心任务分开。
- **分层**：基础/提高/拓展三层；拓展层不纳入核心掌握要求。
- **年级不明**：先问年级或基础，不要默认用高年级方法；若用户要求不明确，给“按某年级假设”的版本并标假设。

## 7. 掌握检查设计

- 出口任务要对应目标，不要考本单元没讲的内容。
- 2–3 题 + 1 个自评/解释任务即可；3–5 分钟内可完成。
- 判据写成可观察行为：能独立列式并检验；能指出错因；能画图说明。
- 未达标给具体补救：回到第几步、重做哪类题、补哪个先修。
- 不写“学生掌握良好”之类无证据结论；只写“若能做到……则视为达标”。

## 8. 单元设计自检

- [ ] 单元计划在内容之前；单元按依赖排序。
- [ ] 一个单元一个独立能力；没有为每个术语单独出题。
- [ ] 11 步齐全且顺序正确；没有一上来堆公式。
- [ ] 目标可检验；先修微任务不计入题量。
- [ ] 方法白名单已列；答案未使用未介绍方法。
- [ ] 基础题只改一个条件；题组有梯度。
- [ ] 易错点有反例/边界；掌握检查有判据与补救。
- [ ] 学科题型、K-12 尺度符合目标学习者。
