# 豆包使用版 · 递进式学案与备课助手

本版以用户在豆包中创建的 `progressive-study-guide` 为基础审核修订。它是 **Skill指令与参考文件**，不需要Codex，不是独立软件，也不附带任何账号或课程资料。支持自学、教师备课、上传母题出变式、中英双语、可选联网找题、来源与额度记录。

当前分支：`doubao/progressive-study-guide`。`main` 保留原版，`feature/authorized-online-research` 保留此前的联网功能分支；本版没有合并到它们。

## 1. 下载

1. 打开 [豆包分支](https://github.com/C-xudco/course-study-guide/tree/doubao/progressive-study-guide)，确认分支名是 `doubao/progressive-study-guide`。
2. 选择 **Code → Download ZIP**，或[直接下载此分支ZIP](https://github.com/C-xudco/course-study-guide/archive/refs/heads/doubao/progressive-study-guide.zip)。
3. 解压后找到 `platforms/doubao/progressive-study-guide`。**需要安装的是这整个文件夹**，不是整个仓库，也不是其中单独一份 `SKILL.md`。

文件应当是：

```text
progressive-study-guide/
  SKILL.md
  references/
    mode-self-study.md
    mode-teacher.md
    mode-variant.md
    question-evaluation.md
    bilingual-and-output.md
    online-research.md
  assets/
    source-catalog-template.md
```

## 2. 安装到豆包本地Skill目录

本项目依据用户实际提供的豆包Windows安装目录整理；**不保证每个版本、账号配置或其他系统使用同一路径**。如果你的豆包已经能创建Skill，优先沿用它实际生成的目录。

这次提供的目录可写成不包含个人用户名的形式：

```text
%LOCALAPPDATA%\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills
```

1. 在资源管理器地址栏粘贴上面路径，确认它是当前豆包使用的目录；若不存在，不要通过新建整条路径来假装已安装。
2. 若已有同名文件夹，先把**整个旧文件夹备份到 `.user_skills` 目录外**，避免重复技能被同时识别。
3. 将下载的 `progressive-study-guide` 整个文件夹放入 `.user_skills`，使文件位置为 `.user_skills\progressive-study-guide\SKILL.md`。避免多嵌套一层。
4. 按当前豆包界面提供的刷新/重新加载方式加载；若没有相应入口，可重新打开豆包后新建对话测试。请以实际界面为准，本项目不假定存在“导入ZIP”等特定按钮。

本仓库里的通用Skill位于 `skills/course-study-guide`，该目录不是本次豆包原生版的安装目录。

## 3. 开始使用

把资料上传到豆包当前对话，或使用它确实有权限读取的附件/工作区。在对话里直接说：

```text
请使用“递进式学案与备课助手”（progressive-study-guide）。
根据我上传的讲义整理第1—3章，自学模式，中英双语。
先讲直觉与先修，再讲定义、条件和解题通法。
每单元2道基础题、1道母题，每道母题3个变式，由易到难。
题组后放完整双语答案，开头有关键词检索，最后有掌握核对表与术语表。
先交付可编辑正文；若有真实文件生成工具，再导出PDF并核对排版。
```

教师备课：

```text
使用 progressive-study-guide，为小学四年级“长方形周长”备课。
中文，40分钟，使用我上传的2道母题，每题4个变式，不另增母题。
给具体教学活动、支持/核心/拓展练习、出口检测。
分别给学生无答案版与教师详解版，题号一致；标注预估难度及考查维度。
不生成模拟卷。
```

只做母题变式：

```text
使用 progressive-study-guide，只处理我上传的3道母题。
每道生成2个变式，不出基础题；包含条件变化、逆向或辨错，别全部只换数字。
逐题给母题关联、变化目的、独立详解、五维难度依据与置信度。
```

题量支持总母题数、每单元数、逐题设置、0变式和0模拟卷；默认完整单元为2基础＋1母题＋3变式=6道练习，示范题等另计。上传母题默认保留，明确选择部分时按选择。

## 4. 联网、账号授权与使用额度

联网默认关闭，明确要求时启用。例如：

```text
使用 progressive-study-guide，联网查找我指定学校这门课程已正式发布的复习资料。
我会提供课程起始链接和允许域名，登录/SSO由我在网站正常界面完成。
官方课程材料优先，知乎/GitHub/CSDN仅作补充线索；按章节、年份、题型分类并核验。
本次搜索最多10次、页面读取20次、下载尝试3次，不付费不扣点。
80%时提醒，触顶停止相应操作并整理已有内容。附来源表、完整答案和用量摘要。
如果你没有可交互浏览器或正规连接器，只查公开资料，我会自行下载后上传其余材料。
```

学科网等资料站同样先核验权限和使用范围。**不要把密码、验证码、Cookie或令牌发给助手。** 普通搜索能力不能自动使用校园登录状态。真实网站余额不可见时写“未知”；本次任务预算不是网站账户余额，模型用量也不能凭空估计。

本版通过指令要求记录真实调用和提醒，**没有自动计量程序、账号连接器或通用SSO登录器**。实际搜索、登录页面操作、文件生成取决于豆包当前可用工具。详见 [联网规范](progressive-study-guide/references/online-research.md)。

## 5. 补充资料、导出PDF与普通聊天备用方式

- **续作**：提供上一批正文/续作记录和新资料，说“沿用题号，比较新增与冲突，更新受影响知识点、母题、变式、答案和索引，保留已审核修改”。不会后台监控，也不会自动读取其他对话。
- **PDF**：若豆包能生成文件，下载后检查中文、公式、表格和答案；否则将正文复制到Word/WPS，检查后导出PDF。只有已经生成的PDF才能离线打开，复制提示词不会自动生成下载文件。
- **普通聊天无Skill功能**：把 `SKILL.md` 和本次模式对应参考文件的正文放入同一对话；出题时补上评价规范，双语/完整学案补上双语与输出规范，联网时补上联网规范和台账模板。只粘贴文件路径不能让模型读到文件。这是手动提供指令的备用方式，不等同安装原生Skill。
- **考试资料限制**：以教师实际要求为准。允许自制PDF不等于允许考试中联网或使用AI；材料应考前生成并核查。

## 6. 安装后的验收与已完成检查

建议在你的豆包版本里用原创小题测试：上传2道长方形周长母题，要求“只出变式，每母题2道，中文，学生/教师两版”。期望保留2道母题＋4道变式，新增基础题和模拟卷均为0；两版题号一致，学生版不泄漏答案，教师版每题有独立解答与评价。再要求“每母题变式改为0”，应保留母题并更新数量与索引。

本次完成的是文件静态审核、引用与格式检查、公开内容检查；修订说明见 [审核记录](REVIEW.md)。**尚未在豆包界面执行端到端对话测试**，不能把文件通过检查等同于所有模型输出都正确。识别不到时先检查真实目录、嵌套层数和文件是否齐全，再按当前豆包说明加载。
