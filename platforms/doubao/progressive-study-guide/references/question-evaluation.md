# 题目评价与答案规范

## 题目标注格式

每道题在题号后或题尾标注：

```
【知识点】[考查的核心知识点]
【能力维度】概念理解 / 程序运算 / 推理论证 / 表征转换 / 情景应用（可多选）
【认知过程】记忆 / 理解 / 应用 / 分析 / 评价 / 创造（可多选，Bloom分类）
【预估难度】X/5级
  - 判断依据：先修要求X、推理步骤X、抽象程度X、迁移要求X、表征复杂度X（各1—5分）
  - 置信度：高/中/低
```

## 难度评分法

五个维度各打1—5的整数分，附题目中的具体依据。等权平均，按非负数四舍五入（half-up）取1—5级，保留原始五项与均值以供复核；例如(1,2,2,2,2)均值1.8，预估2级。

| 维度 | 1分 | 5分 |
|------|-----|-----|
| 先修要求 | 只需本单元知识 | 需要多单元/跨章节综合 |
| 推理步骤 | 1—2步直接计算 | 4步以上、需中间转化 |
| 抽象程度 | 具体数字、直观情境 | 纯符号、多变量、形式化推理 |
| 迁移要求 | 原题型直接套用 | 需识别题型、自主选择方法 |
| 表征复杂度 | 单一文字表述 | 需结合图表/多条件/隐含信息 |

2分表示轻度增加先修/转换，3分表示需要数个有联系的判断或常见迁移，4分表示多环节综合或不熟悉的表征；结合上表各维度分别判断，不只数算式行数。推理步骤应数有效决策与转化，不能把重复计算写长就判成高难度。

同一题对不同年级和已学范围可能不同，先声明学习者基线。置信度说明来源：条件完整且可验算可较高；学生基础未知或开放题评分标准未定时降低。低置信度不等于低难度。题量、完整解答与评价是否齐全必须逐题核对。

**重要：** 认知过程层次不直接等于难度。"创造"类题不一定比"应用"难。没有真实答题数据时，只能称"预估难度"，**不得编造正确率、区分度或实测结论**。

## 答案编写规范

答案集中放在对应题组之后，每题包含：

```
### 答案：U01-B01

**方法**：[用什么方法，为什么选这个方法]

**步骤**：
1. [第一步] —— [这步做什么、依据什么]
2. [第二步] —— ...
3. [结论] —— [最终答案 + 单位 + 适用条件]

**核验**：[怎么检查结果合理，如代入原式、量纲检查、特殊值验证]
```

## 教师版答案额外要求

教师版每题增加：
- **评分点**：分步给分标准（如"列对方程得2分，求解正确得3分，结论正确得1分"）
- **常见错误预判**：学生最可能错在哪里
- **讲解建议**：课堂上这道题怎么讲、重点提示什么
