# 自学模式工作流

## 适用场景

用户希望自己学习某个知识点或章节，需要：知识讲解 + 分层练习 + 详细答案 + 自查机制。

## 输出结构

```
# [学科] [章节/主题] 自学学案

## 检索表
（见 bilingual-and-output.md 中的索引表格式）

## 单元 U01：[单元标题]
### 学习目标
（一条可检验的目标句，如"能独立用洛必达法则求 0/0 型极限"）

### 情景与直觉
用生活例子或直观现象引入，不超过3段。

### 必要先修
列出学本单元前必须掌握的知识点，附简要回顾。

### 术语和定义
本单元核心术语，每条配定义和一个例子。

### 原理及条件
公式/定理/法则，**重点写明成立条件和适用边界**。

### 完整示范
一道从题干到结论的完整解题示范，每步写理由。

### 解题通法
总结本类题的通用步骤（编号列表）。

### 易错辨析
列出3—5个常见错误，每个配错误示例→为什么错→正确做法。

### 分层练习
- 基础题：直接套用刚学的方法，按本次配置生成（默认2道/单元）
- 母题：综合运用本单元核心方法，按本次配置或上传题目生成（默认1道/单元）
- 变式：按逐母题配置生成（默认每母题3道），见 mode-variant.md

### 答案与详解
集中放在本单元练习之后。

### 掌握检查
3—5条是非题或自查问句，让学习者检验是否掌握。

## 单元 U02：...
（重复以上结构）

## 掌握核对表
（见 bilingual-and-output.md）

## 术语表
（见 bilingual-and-output.md）
```

## 自学模式特殊要求

1. **主动补先修**：如果学习者基础不够，在"必要先修"部分给出简明回顾，不假设已掌握。
2. **即时反馈**：基础题答案紧跟题组，不要把所有答案放到最后。
3. **难度递进**：基础题 → 母题 → 近迁移变式 → 综合迁移，整体逐步上升；辨错或条件辨析可同级巩固，不强迫每个变式都比母题难。
4. **鼓励性语言**：讲解中适当加入"这一步为什么这样想"的思路旁白，像家教在旁边讲题。
5. **检索友好**：每个知识点和题目都有编号，方便回头查找。
