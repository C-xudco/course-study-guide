# 教师模式工作流

## 适用场景

教师需要备课，输出完整教案 + 学生练习版 + 教师答案版。

## 教案结构

```
# [学科] [章节] 教案

## 基本信息
- 年级：
- 教材版本：（未确认则标"待确认"）
- 课时：第X课时，共X课时
- 课型：新授课/习题课/复习课

## 教学目标（可观察、可测量）
用"学生能……"开头写3—4条，区分：
- 知识与技能：记住什么、会做什么
- 过程与方法：经历什么过程、掌握什么方法
- 情感态度：（可选）

## 教学重点与难点
- 重点：本课时核心知识/技能
- 难点：学生容易卡壳的地方 + 突破策略

## 教学过程

| 环节 | 时间 | 教师活动 | 学生活动 | 设计意图 | 预期误解 |
|------|------|----------|----------|----------|----------|
| 导入 | 5min | ... | ... | ... | ... |
| 新授 | 15min | ... | ... | ... | ... |
| 练习 | 15min | ... | ... | ... | ... |
| 小结 | 5min | ... | ... | ... | ... |

**各环节时间合计必须等于总课时。**
表中的40分钟仅为示例；出口检测计入练习或小结时间，不额外叠加。所有时间按用户指定课时重新分配。

### 分层练习设计
- 支持层：基础薄弱学生能完成的题
- 核心层：全体学生应掌握的题
- 拓展层：学有余力学生挑战的题
不使用"差生/好生"等标签评价学生能力。

## 板书设计
主板书（核心框架）+ 副板书（演算区），用文字描述布局。

## 出口检测
下课前2—3分钟的1道检测题，检验目标达成。

## 课后反思记录框架
（只给空白框架，不虚构课堂效果）
- 目标达成情况：
- 学生主要困难：
- 下次改进：
```

## 学生版与教师版

- **学生版**：保留题目和作答空间，**不含答案、评分点和评价依据**。
- **教师版**：在学生版基础上，每题附答案、评分点（分步给分）、常见错误预判和讲解建议。
- 两版沿用相同题号和题干；检索表在学生版仅指向题目，不显示答案位置或提示性评价。不要在学生版末尾意外附上完整答案或教师备注。

输出时先说明"以下是教师版"或"以下是学生版"，两版都提供时分开标注。

## 教师模式特殊要求

1. **按年级控制深度**：低年级优先直观情境、图示、操作和短句；不用超纲知识制造难题。
2. **教材版本待确认时**：明确标注"教材版本待确认，本教案按通用体系设计"，不宣称已对齐课标。
3. **课堂活动要具体**：不说"组织小组讨论"，要说"4人一组，讨论3分钟，第3组分享"。
4. **母题变式用于课堂**：母题教师讲，变式学生练，按难度分层布置。
5. **默认不生成模拟卷**，除非用户明确要求考试复习。
