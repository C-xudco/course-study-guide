# 母题变式模式工作流

## 适用场景

用户上传母题/例题，要求生成同类型变式题。

## 母题解析流程

上传母题后，先逐项核对：
1. 题干文字是否完整
2. 数据/数值是否清晰
3. 图示（如有）内容是否可辨
4. 原答案/适用条件是否随附

然后提炼母题结构：

```
母题编号：U01-M01
已知信息：[列出所有已知条件]
所求目标：[问什么]
核心关系：[用到的公式/定理/逻辑链]
关键判断：[解题时最关键的那一步决策]
通用步骤：[1. 2. 3. ...]
核验方法：[怎么检查答案对不对]
```

## 变式编号规则

```
U01-M01       → 第1单元第1道母题
U01-M01-V01   → U01-M01 的第1道变式
U01-M02-V03   → U01-M02 的第3道变式
```

## 变式类型

一组变式中**不能全部只换数字**，必须混合以下类型（除非用户明确说只要同构练习）：

| 类型 | 说明 | 训练目的 |
|------|------|----------|
| 参数变化 | 换数字、换单位、换具体数值 | 巩固基本程序 |
| 条件变化 | 增减条件、改变前提 | 理解条件对结论的影响 |
| 图文表征变化 | 文字题↔图表题↔公式题互换 | 训练表征转换 |
| 逆向求解 | 已知结论反推条件 | 深化对因果关系的理解 |
| 错误诊断 | 给出错误解法，找错并改正 | 暴露常见误区 |
| 情景迁移 | 换一个生活/学科背景，方法不变 | 训练迁移应用 |

## 每道变式必须标注

```
变式编号：U01-M01-V01
母题来源：U01-M01
改变了什么：[如"把匀速改为匀加速"]
保留了什么：[如"追及问题的核心关系不变"]
训练目的：[如"练习加速度引入后的位移公式"]
```

## 题目数量规则

- 用户说"母题共3道" → 本次任务总共3道母题，不是每单元3道。
- 上传母题数量超过预设时，**说明实际题量，不静默丢弃**。
- 用户明确选择部分题目时按其选择。
- 默认保留所有适用的上传母题。

## 变式求解要求

- **每题独立求解**，不能假设和母题同方法就不验证。
- 检查每道变式的条件是否自洽、答案是否存在。
- 无解、多解或开放答案必须明确说明。
- 附完整答案和解析。
